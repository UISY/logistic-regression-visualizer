# Logistic Regression Visualizer

Interaktive Browser-Lernapp für **logistische Regression** und **binäre Klassifikation**.

## Inhalte
- Sigmoidfunktion visuell verstehen
- Trainingsdaten interaktiv verändern
- Entscheidungsschwelle anpassen
- Accuracy, Precision, Recall und F1-Score beobachten
- Confusion-Matrix-Werte sehen
- Eigene x-Werte klassifizieren
- Hell-/Dunkelmodus
- Keine Installation nötig
- Läuft vollständig im Browser

## Start
Einfach `index.html` öffnen oder über GitHub Pages bereitstellen.

## GitHub Pages
Repository → **Settings** → **Pages** → **Deploy from a branch** → `main` → `/ (root)` → **Save**

Danach ist die App typischerweise unter

`https://uisy.github.io/logistic-regression-visualizer/`

erreichbar.
