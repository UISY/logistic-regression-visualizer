SCHRITT 1

Was macht logistische Regression?

Sie sagt nicht direkt eine beliebige Zahl voraus, sondern zuerst eine Wahrscheinlichkeit zwischen 0 und 1. Daraus wird anschließend eine Klasse abgeleitet, zum Beispiel 0 = kein Ausfall und 1 = Ausfall.

Eingabe x

Zum Beispiel Temperatur, Verschleiß oder Messwert.

Wahrscheinlichkeit

Das Modell berechnet P(Klasse 1).

Klasse

Ab einer Schwelle wird aus der Wahrscheinlichkeit Klasse 1.

p = 1 / (1 + e−(b₀+b₁x))

Die typische S-Kurve heißt Sigmoidfunktion. Kleine x-Werte liegen eher nahe 0, große x-Werte eher nahe 1. Die Entscheidungsschwelle ist standardmäßig oft 0,5 – sie kann aber je nach Anwendung angepasst werden.

Was bedeutet die Schwelle?

Liegt die vorhergesagte Wahrscheinlichkeit über der Schwelle, wird Klasse 1 vorhergesagt. Eine niedrigere Schwelle erkennt meist mehr positive Fälle, erzeugt aber oft auch mehr False Positives.
